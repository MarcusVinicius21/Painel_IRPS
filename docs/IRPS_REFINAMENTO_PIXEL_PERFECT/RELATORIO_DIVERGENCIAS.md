# Relatório de divergências — refinamento local

**Resultado global: REPROVADO para fidelidade visual integral.** Houve implementação e melhora verificável da geometria principal. A tolerância de caixas não substitui a revisão de controles, densidade e acabamento. Não se atribui percentual de pixel-perfect.

## Dependências de dados

- 348.679 códigos dos arquivos fornecidos são pesquisáveis; isso não equivale a compras vinculadas.
- A última evidência preservada mostra 0 códigos com vínculo oficial revisado. Os indicadores por código dependem dessa vinculação técnica.
- Não foram expandidas fontes nem feita nova coleta externa nesta rodada.
- Estudos internos sem manifestação permanecem pendentes. Amostras sintéticas nunca são certificações de resposta municipal.

## Capacidade real de itens

O estudo da diretoria continua de um item. O núcleo legado suporta múltiplos itens, mas esta rodada visual não criou uma IRP documental multiitem. Repetir cartões não seria implementação desse domínio. Não houve migração de schema nesta rodada.

## Limites do método

Caixas manuais de referência em inventario.json. Comparação usa DPR 1, fontes carregadas, animações desligadas e rolagem no topo. Mapas de diferenças incluem texto, dados, anti-aliasing e desenho; erro médio RGB não é percentual de fidelidade. A fixture sintética altera somente respostas interceptadas no contexto isolado do navegador. Não é modo produtivo nem fica disponível por query pública.

## Revisão de implementação

React mantém hooks no topo, identidade estável de municípios e snapshots, APIs independentes e guardas de corrida existentes. Não foi introduzida biblioteca de componentes ou substituição de stack. Persistência, permissões e cálculos continuam no backend. CSS compartilhado concentra os tokens e breakpoints, mas ainda tem regras específicas de refinamento; há dívida de manutenção para consolidar a cascata sem perder as medidas.
