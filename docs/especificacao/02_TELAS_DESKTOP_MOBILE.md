## Mapa de navegação

Entrada → Início → Busca → Resultados → Item/Município → Processo → Pagamentos. Comparação e Necessidades ligam-se ao mesmo contexto. Montar Licitação → Cidades/Itens/Quantidades/Meta/Preços/Revisão → Relatórios. Memória retorna ao item/cidade. Meu negócio tem espaço separado. Documentos, Fontes, Alertas e Administração completam o ciclo.
