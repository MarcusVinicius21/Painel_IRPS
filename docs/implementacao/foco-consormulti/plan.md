# Integração visual FCP

Preservar shell Observatório, login operacional, componentes Page/Panel/Field/DataTable/Notice e cliente HTTP/CSRF. Acrescentar uma rota portfolio, sem frontend paralelo. Entrada operacional após login aponta ao portfólio; módulos existentes continuam navegáveis.

Fluxo: vinte grupos → código/snapshot e motivo técnico/comercial → guia preços nacionais → grupo municipal ou código com vínculo comprovado → evidência oficial/fornecedor → planejamento existente. Código e snapshot seguem juntos ao planejamento; filtros do portfólio persistem no backend. Candidatos textuais municipais não se tornam vínculo CATMAT ou necessidade V4.

API de grupos e código paginada; guias carregadas sob demanda e independentemente. Busca/filtros têm aplicação explícita; comprador recebe CNPJ completo antes da consulta. Estados vazios e falhas são visíveis. Nenhuma série decorativa ou total fictício.

Design: tokens e componentes atuais, coluna de grupos com lista compacta, área de consulta principal e guias. Mobile empilha as áreas e mantém tabela/cartões responsivos existentes. Textos seguem Humanização IRPS. Testes headless, sem screenshots, em 320/390/1536 px, com teclado e axe no conteúdo novo. Não afirmar pixel-perfect.
