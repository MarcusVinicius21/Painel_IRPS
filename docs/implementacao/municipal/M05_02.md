# M05_02 — Fronteira versionada de portal, ingestão não habilitada
Status: PARTIAL

Reutilizados o inventário M05_01 e o esquema JSON efetivamente documentado no portal delegado de Ipatinga. Não foi criado raspador genérico ou parser CSV/XML com colunas presumidas. `backend/app/municipal_portal_adapter.py` valida respostas salvas de `/api/pagamentos`, cliente 97, schema actcon-ipatinga-payments-observed-v1. Exige sources.sync, HTTPS, destino/parâmetros exatos, período de um exercício, página limitada, tamanho de resposta e hash íntegro. Não abre arquivo, faz HTTP ou altera banco.

HTTP 429/503 retorna retry_later com intervalo limitado e zero tentativas automáticas; 404 permanece indisponível; HTML/layout alterado, JSON inválido ou objeto em lugar de lista são rejeitados. Página fora do período é integralmente rejeitada. Candidatos compatíveis recebem recibo determinístico por schema, URL, período e hash, mas permanecem sujeitos a revisão e **não são importados**. Não se apresenta repetição do recibo como idempotência de uma gravação ainda inexistente.

Validação real executada com o contexto autorizado do operador, transação READ ONLY no PostgreSQL e as duas respostas oficiais salvas de M04_03: ambas retornaram **SOURCE_PERIOD_MISMATCH** (consultas 2025/2026 contendo registros de 2010). Evidência privada financial-discovery/adapter-validation.json. Nenhum evento financeiro, quantidade, vínculo, saldo ou cobertura foi criado. Timóteo permanece indisponível por 403; não há outra fonte municipal com esquema e recorte aprovados para habilitar ingestão.

Testes: `.venv/Scripts/python.exe -m pytest backend/tests/test_municipal_portal_adapter.py backend/tests/test_municipal_finance.py backend/tests/test_municipal_portals.py -q`: **31 aprovados**, 0,26 s. Incluem layout, 429/503, 404, parser, hash, permissões antes de IO, URL fora do escopo, retorno temporal indevido, recibo repetível e dados faltantes. `git diff --check` aprovado. As fixtures são sintéticas e exclusivas dos testes, sem carga no operacional.

**Não implementado/testado como ingestão:** persistência de lotes por órgão/mês, revisões financeiras e reconciliação com compras. A pendência é a validação do comportamento temporal e da identidade financeira do exportador; habilitar só porque HTTP=200 corromperia o recorte. Fontes somente PDF tampouco foram convertidas em fatos; não foi encontrado contrato estruturado adicional nesta tarefa. Sem migração, alteração de frontend, fórmulas V4, imagens, serviço pago ou publicação remota. Prosseguir para M06_01, independente desses bloqueios.
