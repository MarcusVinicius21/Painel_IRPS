## Código e validação
`buyer_identity()` compara exatamente CNPJ completo, unidade e IBGE; raiz fiscal é atributo separado, nunca chave suficiente para fundir unidades. `scripts/censo_compradores.py` aplica filtro explícito de organização, vincula o ID PNCP da publicação à resposta arquivada e preserva URL/hash/data; conflitos ficam ORGAO_NAO_VERIFICADO. Provas privadas em `.runtime/irps-municipal/buyers.json`. Nenhum schema ou fato foi alterado.

Executados censo real (9/9 identidades verificadas), probe SQL somente leitura com filtro de outra organização (zero compradores) e ausência de compradores não oficiais de terceiros. `python -m pytest backend/tests/test_municipal_campaign.py backend/tests/test_municipal_checkpoint.py -q`: **16 aprovados**. Casos de esfera estadual/federal, Câmara, poder ausente, outra unidade e outro município.

Uma primeira asserção de diagnóstico esperava isolamento de TODOS os compradores e falhou: a política original public_or_tenant permite SELECT de registros oficiais entre organizações. Após examinar a migração original, o teste foi corrigido para verificar o contrato real, mantendo explicitamente o filtro da organização no novo censo. Não se alterou RLS para acomodar o teste. Não foi executada nova suíte HTTP/RLS completa nesta tarefa; fica para QA de infraestrutura.
